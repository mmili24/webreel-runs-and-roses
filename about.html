Què és Runs & Roses?

Runs & Roses és un joc de plataformes 2D creat per Sant Jordi. El personatge ha de recollir roses per les plataformes abans que s'acabi el temps.

Tecnologies

El joc està fet amb Phaser 3, Vite i Bun. El WebReel que el presenta està fet amb HTML, CSS i JavaScript vanilla.

Autora

Projecte desenvolupat per Marija com a part del CFGS DAW a l'Institut MVM de Barcelona.

Llicències

Tots els recursos utilitzats (música, imatges, fonts) disposen de llicència lliure. Els detalls es troben al README del repositori.
